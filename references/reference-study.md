# Reference study: absorb excellent vlog practice (without copying)

Use this before locking the visual system or writing the shot table for a **new production / full redo** — not for a small local patch unless the user asks.

## 1. Pick 3–5 references

- Same platform, genre, and rough duration (e.g. 45–60s vertical campus/travel vlog).
- Mix 2–3 proven high performers with 1–2 adjacent references (a brand film, a documentary short, a creator you like) for fresh structure.
- Prefer links you can revisit; note creator/platform/date. Do not re-upload or redistribute the videos.
- If the user already gave references, use them first.

## 2. Extract principles, not shots

For each reference, fill a row:

| Reference | Hook 0–3s (image / words / sound) | Structure (shots, avg shot length, A/B ratio, cards) | Packaging (title, subtitles, color, transitions) | Sound (voice/BGM/SFX/ambience) | Why it works (one sentence) | Transferable principle | Surface element (do not copy) |
|---|---|---|---|---|---|---|---|

Look for:

- **Hook:** what makes you stop in the first 1–3 seconds? Is it a number, a contradiction, a face, a sound, a question?
- **Structure:** total shots, average shot length, talking-head vs B-roll ratio, where fact cards/end cards sit, how the story turns.
- **Packaging:** title hierarchy, subtitle size/position/line length, color palette, transition grammar, information density.
- **Sound:** voice level, BGM role, SFX, ambience, silence.
- **Context:** why it works for *that* audience/platform — not just “it looks nice”.

## 3. Synthesize before creating

Write a one-page `reference-study.md` in the project with:

1. **3 principles to adopt** (e.g. “open on the counter number, not the building”; “change visual every 2–4s”; “one idea per fact card”).
2. **2 things to avoid** (e.g. “do not copy the exact hook”; “do not use the same BGM”).
3. **2–3 creative options** for this brief, with a recommendation and why.
4. **What not to copy:** shot-for-shot edits, faces, music, logos, copyrighted assets, another creator’s voice.

Then write the production spec / visual system. The reference study informs choices; it does not replace the material audit or the review gates.

## 4. Honesty / ethics

- Cite links in the project notes; do not imply the reference creator endorses the work.
- Do not download/re-upload copyrighted videos; extract notes and your own frames only where permitted.
- If a reference’s look depends on a location/person you do not have, translate the *principle*, not the surface.
- Do not let “reference” become “template”: the final piece must fit the actual footage, facts, and brief.

## 5. Gate

For a new production/full redo:

- [ ] 3–5 references studied, with links/notes.
- [ ] `reference-study.md` written: 3 principles, 2 avoids, 2–3 options.
- [ ] At least one principle is visibly used in the script/visual system.
- [ ] No copied assets/faces/music; no shot-for-shot recreation.
